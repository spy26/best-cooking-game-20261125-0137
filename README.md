Sizzle & Serve — Rush Hour Kitchen: a complete top-down cooking game that runs offline in a desktop browser from static files. One warm bistro kitchen, an order board with ticking tickets, a pantry, a chopping board, a two-slot grill and an assembly counter. Chop the tomato, grill the patty to the perfect window (too long and it burns), stack each dish in recipe order, and serve it before the ticket's patience runs out. Five recipes, combo multipliers for back-to-back serves, and a rush hour in the last minute when tickets arrive faster and patience runs shorter.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

WASD / arrows move, E (or Space) interacts, 1-5 take pantry ingredients (1 Bun, 2 Patty, 3 Tomato, 4 Lettuce, 5 Cheese), click a station to walk to it, P pauses. A shift lasts 3 minutes; 3 expired orders end it early. Screenshots: `?shot=start|play|rush|serve&seed=7` stages each scene; `?selftest=1` runs the rules headless.
